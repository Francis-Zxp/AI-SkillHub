## 二、性能

- 动物 FBX 转 glTF 后每只有 17–106 个蒙皮子网格。运行时按根骨骼与颜色合并（统一为非索引 position/normal/skinWeight/skinIndex），试景绘制调用从 1474 降到 653，预览数据下 373。
- 动物尺寸用蒙皮后的精确包围盒归一化。
- 天空岛素材总量约 4.5 MB（v3.2.8 约 6.3 MB）。

- 此刻核对：56 个 Git 仓库 HEAD 中共 1,092 个 SKILL.md，磁盘缺失 0。
- 例外：`autoresearch--karpathy` 是旧版导入的 Prompt 来源（非锥形 `/*.md`），上游目前没有 SKILL.md；根目录 Markdown 能更新，但若作者以后新增 Skill 目录或项目文件不会落盘，且与新版导入（Prompt 仓库取消稀疏）不一致。`mineru-document-extractor` 无 Git 与上游地址（ClawHub 手动导入），无法自动更新，需要重新导入。
