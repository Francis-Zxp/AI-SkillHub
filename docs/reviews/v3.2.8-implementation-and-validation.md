## 二、视觉任务书逐项

**素材与许可**：Quaternius 的 Stylized Nature / Medieval Village / Fantasy Props MegaKit 与动画女性村民（CC0），Poly by Google 的飞行海鸥（CC-BY 3.0，需署名）。只随包分发经构建脚本处理后的产物（`app-next/public/sky/`，约 6.3 MB），离线可用。来源、作者、许可与修改见 `docs/assets/sky-island-assets.md`、`public/sky/ATTRIBUTION.txt`，应用内天空岛页“素材与许可”。

**方向试景**（同一份真实分类数据、真实素材）：A 晨光地图俯视、B 高空侧视、C 暮色。选择 B 作为亮色主题，暮色光照套用 B 的机位作为暗色主题（切换主题时岛屿位置不变）。理由：B 能同时看到岛顶内容和岛底地质，云海与远景岛给出纵深，构图横向舒展；A 层次扁平，C 单独使用时岛面偏暗。截图：`app-next/reports/visual/v3.2.8/directions/`。

| 要求 | 结果 |
| --- | --- |
| 一类一岛、面积可理解、空分类可点 | 半径 ∝ √(Skills 数 + Prompt 来源数)，有最小可点尺寸；页面写明计数口径 |

## 三、修复清单（本轮发现并修复）

- `last-sync.json` 带 BOM 时 Rust 解析为空，部分同步被显示为完成。
- 依赖目录识别把上级目录当依赖（会拉下整个 `skills/`）；改为跳过祖先并限制单个依赖文件数。
- Tauri CSP 不允许本地 GLB 与 blob 贴图，打包后 3D 场景会加载失败；已补 `connect-src 'self' blob:`、`img-src blob: data:`。
- 星图主包超出体积预算：改为与天空岛一样按需加载，主包回到基线以下，没有调高预算。
- 首页触控条“更新全部来源”在小窗口折成两行。
- 星图缓存键升级，避免旧缓存显示旧命名。
