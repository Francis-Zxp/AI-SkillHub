# v3.2.13：侧栏面板与星图文字

用户最终明确：圆角菜单面板保留，面板外围与页面背景连续。3.2.12把首页整条侧栏透明化是对需求的误解；本版按此纠正，保留各主题配色。

## 修复

- 侧栏由透明布局容器及一个圆角底板构成。删除Atlas整列底色、Sky独立面板和首页隐藏面板三套冲突规则；所有主题、所有页面共用面板结构，经典主题保留原有宽文字导航。上下留白12px。
- 星图介绍补足侧栏安全距离，恢复面板后不遮挡介绍。
- 星图名称原本每帧调用Canvas绘字；3.2.12自动旋转仍被限制为30fps。现在文字用持久DOM合成层，位置与节点同步更新，不逐帧写入内容或重新绘字；空闲旋转采用屏幕刷新节奏，绘制耗时大于18ms时允许降帧。
- 保留名称避让、原文字大小、来源作者层级、交互命中、DPI处理、减少动态效果和隐藏页暂停。标签使用textContent，外部来源名不会作为HTML执行；缓存有界。

主要文件：`app-next/src/{styles.css,sky-theme.css,HomeScene.css,SkillUniverse.tsx,SkillUniverse.css,universeLabelLayer.ts}`。更新已有排版与星图检查，使它们检测新的文字层与面板结构。
