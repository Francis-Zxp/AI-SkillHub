# AI SkillHub 3.2.11 实施与验收

日期：2026-10-02。基线：c4075de（3.2.10）。本轮授权包括本机覆盖安装、源码推送和 GitHub 正式发布。

## 问题、原因与修复

| 反馈 | 原因与处理 |
|---|---|
| 云像白面包 | 原实现为多个不透明球壳；改为柔边、连续密度的轻量云片，保留昼夜颜色和空间漂移。无新增下载依赖。 |
| 繁星抢主视野 | 星点整体降亮，并按中心距离和边距双重渐隐，外侧 10% 保持无背景星点。 |
| 光晕位置 | 选择较弱的右上侧光，球体内部保留柔和亮度变化；数据节点的小高光方向一致。 |
| 数据颜色粉彩难区分 | 增加分类色饱和度，降低近处节点过高的明度，保留形状与状态区别。 |
| 名称旋转闪烁 | 原来每帧按半径/深度重新排序抢位；改为稳定优先级、保留标签方向、短遮挡迟滞和换位前渐隐，像素对齐文字。 |
| 来源命名布局 | 组件缺少样式；补齐独立懒加载样式、数字基线、说明折叠和有界列表。 |
| 岛底尖刺与土层 | 删除附加尖锥，保留一个连通岛壳，草地下浅土色连续过渡为深岩色。 |
| 左栏阴影 | 去掉天空主题的侧栏阴影，保留边界线，不给其它主题扩大样式覆盖。 |
| 四页面切回首页卡顿 | 原来卸载并重建 GPU 场景；首次进入后保留一个场景与相机，隐藏时停止 RAF，零尺寸不清空缓冲，恢复时重新测量。关闭 3D 或上下文丢失仍释放。 |
| Codex MCP 配置无法解析 | 真实 TOML 合法，含非 MCP 的数组表；旧逐行解析器遇到 [[...]] 就拒绝。改用现有 toml_edit 严格解析；重复表、错误类型仍拒绝，不修改真实配置。 |
| Origin 大段说明/错误状态 | 补局部样式和折叠步骤，长命令可换行复制；首次检测失败可重试、安装失败信息不被重检清空。Origin 未打开明确要求先打开，不误称必须重新注册。 |
| 发布门禁 | 修复旧版远端 Rust 新版本 Clippy 报告的两处不必要借用，没有关闭检查。 |
