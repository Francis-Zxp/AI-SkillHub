# v3.2.12：运动、排版与 Origin 桥接修复

基线：`6d0728901a22802a02a234d77f5fac6becba8437`（3.2.11）。本轮按实际运动、原生连接和界面布局验证，不以静态截图或构建成功代替交互验收。

## 修复与证据

| 用户反馈 | 成因与改动 | 验证 |
|---|---|---|
| 缩放、移动后云持续闪烁 | varying 中的整数种子经插值产生浮点末位误差，sin/fract 哈希将其放大；片元中恢复整数种子 | 同一80帧微移实验：明显突变像素峰值14,764→0；平均RGB差0.860649→0.000425 |
| 水潭接瀑布是90度折角 | 独立平面拼接导致切线突变；改成水平、圆弧与垂落相连的一个曲面，UV连续 | 相邻段切线转角小于10度；日间近景、4K夜景和真实缩放录屏 |
| 动物漂移、腿不带动 | 模型导出保留足部控制轨迹但丢失两节腿IK；恢复IK、支撑脚锁地，位移取足部步幅 | 六种动物动作与蹄部回归；每种30秒支撑期采样、真实场景录屏 |
| 马缺少立体感、鸟总是三只 | 连续受光保留作者毛色、贴图与顶点色；鸟群改为种子稳定的不等群组与单飞 | 马近景及六动物动作图，三种种子的群组数量检查 |
| 星图转动名称抽动 | 拖动骤减名称数量、文字坐标取整、Windows movementX单位与精度问题 | 稳定32个候选上限、小数位置、CSS指针坐标；1,057节点1080p/4K实测 |
| 星图渲染开销 | 静态星场与抖色每帧重画、文字重复测量、定时器后接RAF | 静态背景独立Canvas，缓存文字宽度，RAF直接调度交互；静置2秒文字重测0次、背景重画0次 |
| 繁星消失、流星方向偏 | 多重衰减使星点过暗；位移乘宽高而尾迹使用同一像素长度 | 中心可见、边缘平滑消隐；方形、超宽、竖屏双方向向量共线测试 |
| 球体缺乏体积 | 数据球是平涂圆形加实心高光 | 统一右上光源，数据球用渐变反射光与明暗；不增加全屏泛光 |
| 侧栏多层框线、背景割裂 | 内外边框叠加、首页Canvas只覆盖工作区、高优先级100dvh覆盖留白 | 同窗背景、单层导航、四边相关留白12px；全屏五个标签左移46px并可原位恢复 |
| 中文字体混乱 | 多主题字体栈、细小字号混用 | 离线Noto Sans SC衍生子集，400–700字重；CDP确认实际字体渲染，33项排版检查 |
| Origin已开却找不到Start | 文件部署与Origin App注册被混为一谈 | 两个按钮实际注册；新增注册/启动入口、备份与超时，不关闭或重启工程 |
| Bridge启动仍无法验证 | 作者compact模式没有可选origin_bridge_status，旧代码提前返回 | 缺少可选工具仍执行origin_ping；真实协议2025-06-18、25工具、bridge=running、ping(show=false)=true |

另修复拖动松手触发普通单击而误选节点。测试显式检查场景旋转距离，避免将静止状态的高帧率误认作转动通过。4K真实拖动采样146帧/约2.4秒、帧间隔p95约16.8ms；4,540次连续标签位置采样未发现大于4px的二阶位移突变。受控鼠标释放后650ms绘制35帧；3.2.11同场24帧。帧率为本机Chrome/ANGLE结果，不代表所有显卡。
