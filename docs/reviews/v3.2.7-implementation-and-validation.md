# v3.2.7：分类天空岛与 MCP 导入

日期：2026-10-01。

## 解决的问题

旧首页把每个来源画成一座岛，56 个来源需要七页；面积只有三个档位，无法直观表达分类的内容量。新首页只聚合用户分类，另保留一个未归档入口，没有来源分页。空分类保留，删除分类留下的旧归属进入未归档。

岛上 Skills 数量逐条统计真实子 Skill，排除父路由入口；Prompt 与 mixed 仓库按“Prompt 来源”单列，不把一个仓库冒充若干 Prompt 文档。岛面积在最小可见尺寸与当前最大分类之间连续增长，最大与空分类面积约 6.25 倍。分类栏复用同一计数模型。明确的子项归属优先于来源归属；旧记录只有唯一来源匹配时才继承，避免把同名来源混在一起。

## 场景与操作

- Three.js 0.160.1 本地打包并按需加载，保留原有星图切换。无需联网 CDN、第三方模型或贴图。Three.js MIT 许可随安装资源提供。
- 原创程序化浮岛、草地、花、树、书屋、风车、观星台、画架、池塘、桥及小居民。稳定分类 ID 决定地貌种子，日常进度刷新不会重复生成场景。
- 不规则同屏布局；拖动、滚轮缩放、回到全景、分类搜索和地图定位。点击岛或文字进入真实分类，清除上一轮全局搜索；普通技能库入口恢复全部分类。
- 植被实例化、同材质静态几何合并，约 30 帧上限；暂停/减少动态/页面隐藏停止持续绘制。限定约 830 万渲染像素，保留两种常见 4K 显示配置的原生像素。
- DOM 文字及按钮保持清晰、可键盘操作。无 WebGL、初始化失败或上下文丢失时显示可操作的分类导航。拖动超过阈值不会误触打开分类。
- 不使用大范围泛光或模糊来装饰工具栏。视觉实现是风格化立体微缩场景，并非把参考图直接贴成背景，也不宣称达到电影级建模。

关键文件：`SkillArchipelago.tsx/.css`、`skyIslandModel.ts`、`skyIslandScene.ts`、`skyIslandArtwork.ts`、`App.tsx`。

## MCP 导入

`Ge-Shun/origin-mcp` 根目录没有 `.mcp.json` 或 `mcp.json`，但 README 有明确的 `mcpServers.origin` JSON 示例。旧实现仅检查根配置文件，因此报错。

新实现保留标准配置文件优先，缺失时读取 `README.md` / `readme.md` 内完整的 JSON 或无语言代码块，提取候选并继续使用现有预览、审核及应用流程。重复示例去重；同名不同配置要求手动选择。读取上限 96 KiB、候选上限 24 个，不执行说明中的 shell 命令，不继承密钥值。

真实 GitHub 读取已验证得到 `python -m origin_mcp`。界面说明导入配置不等于安装服务；Origin MCP 仍需要 Windows、有效 Origin/OriginPro、Python 3.10+、Python 包以及 Origin 桥接组件。本次未安装这些依赖，也未修改现有宿主 MCP 配置。依据：[上游仓库](https://github.com/Ge-Shun/origin-mcp)。
