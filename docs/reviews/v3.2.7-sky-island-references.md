# v3.2.7 天空岛：13 个开源项目源码研究

研究日期：2026-10-01。完成于产品实现前。范围是渲染与交互算法，不运行第三方代码、安装脚本或演示；没有编辑产品文件。通过 GitHub 官方 API 获取固定 commit，再从 raw.githubusercontent.com 下载关键源文件与 LICENSE；13 个项目的根许可证均实读为 MIT。源文件与元数据暂存在被 git 忽略的 `reports/research-sky-island/`，正式审计结论在本文件。

这 13 个不同仓库包含完整浮岛案例、风格化环境组件和底层交互/渲染实现；不是 13 套彼此独立的完成品美术。Steve 的草地实现明确受 cortiz 启发。许可结论仅覆盖已读取的代码许可证，不自动覆盖模型、音乐、纹理或商标。使用 MIT 代码时必须保留相应版权及许可；本报告未把“README称MIT”作为唯一证据。

## 先给实现结论

当前 `SkillArchipelago.tsx` 是 SVG 数据群岛，`package.json` 尚无 Three/R3F。要实现真正立体的天空岛，需要引入清晰隔离的 3D 场景层，并继续复用已有来源/文件夹映射、点击动作与 DOM 控件；增加SVG纹理或更多三角形不能替代摄像机、真实地面、光照与物体遮挡。

建议采用“可辨识的主岛 + 少量不同轮廓的卫星岛 + 远景云海”，在选中来源后聚焦它；这是本报告的设计推断，不是某个仓库直接提供的成品。保持标签可读，不把来源名称全部做成随透视缩小的3D字。原群岛/列表应保留为低性能或WebGL不可用回退。Windows 10/WebView2兼容必须实际验收，不能由开发机浏览器结果推断。

### 1. paulrobello/small-world — 完整浮岛世界：岛形与高度场

- 固定 commit：`0416bbcf7dbc58b2782f13698c74ac1dde459613`；[关键源码 `src/terrain.js:30–99`](https://github.com/paulrobello/small-world/blob/0416bbcf7dbc58b2782f13698c74ac1dde459613/src/terrain.js#L30-L99)；[MIT 原文](https://github.com/paulrobello/small-world/blob/0416bbcf7dbc58b2782f13698c74ac1dde459613/LICENSE)。
- 代码机制：islandFalloff 先把世界坐标旋转到岛屿局部坐标；椭圆缩放或圆形减去一块形成肾形轮廓。makeHeightFn 叠加三个频率的噪声，以边缘 falloff 压低高度，并在边缘平整到共同高度。
- 融入方案：用 sourceId/folderId 的稳定种子决定岛形、植被和小屋；轮廓不再是每岛相同的圆锥。上表面与岩石底座分开建模，确保俯视仍有空间层次。
- 风险/不照搬内容：该高度场本身不是闭合悬空岩石网格；需要另外构造侧壁/底座。地面采样另有 Math.random，不可直接当成全程确定性实现。

### 2. cortiz2894/stylized-components — 风格化草：根部稳定、风向一致

- 固定 commit：`1cece0a296b29299d1380c34feb5c158b2f04500`；[关键源码 `src/components/grassField/shaders/grassBlade.ts:80–151`](https://github.com/cortiz2894/stylized-components/blob/1cece0a296b29299d1380c34feb5c158b2f04500/src/components/grassField/shaders/grassBlade.ts#L80-L151)；[MIT 原文](https://github.com/cortiz2894/stylized-components/blob/1cece0a296b29299d1380c34feb5c158b2f04500/LICENSE)。
- 代码机制：草的根点采样泥土遮罩和低频斑块；岩石影响压低草叶。先计算压缩后的高度，再用高度平方控制摆幅。将世界风向乘实例旋转矩阵的转置，修复随机旋转草叶各向摆动的问题。
- 融入方案：每座近景岛使用一个草 InstancedMesh，统一风向、不同相位；石头/道路周围自然稀疏，草根不滑动。
- 风险/不照搬内容：shader 注入依赖 Three shader chunks；版本升级要做画面回归。不要直接带入整套 Next、编辑器和多通道后期。

## 可直接交给实现代理的范围

1. **场景骨架**：独立懒加载天空岛组件；固定生成种子；岛面/岩壁/底座为真实几何；摄像机角度允许看见岛面及底部；主光与天空/雾色统一。先验收没有装饰时的轮廓、空间与缩放。
2. **地面细节**：依真实网格表面采样少量树、草、石块、花和小屋；同类物体实例化；风向一致、草根固定；草与建筑/路径/水域互斥。禁止每帧重新生成布局。
3. **水云角色**：一处可见溪流或小湖、朝明确方向的瀑布；轻量云团前后分层；原创/许可明确的小角色有待机与走路状态。先用简单路径动画，避免一开始加载整套物理。
4. **操作**：拖动/滚轮调整观察范围，点击岛屿触发现有来源/文件夹行为；点击标签、键盘和详情仍使用DOM；清楚显示选中项，拖动不误触点击。
5. **性能与降级**：限制有效DPR、可见岛数、草实例、透明云覆盖和阴影贴图尺寸；窗口不可见时停帧，减少动态模式冻结持续运动；WebGL失败回退现有群岛。水面反射和重后期默认为可选，不以WebGPU为前提。

以上参数应通过实测选择，不承诺某个草量或某个显卡的帧率。主岛的几何和材质优先于大范围Bloom、描边和Kuwahara后期，避免再次出现条栏灰影/光晕干扰阅读。

## 验收证据必须区分

- **结构**：来源/文件夹总数与选中对象保持真实；无随机布局跳变，主题切换不会遗留GPU资源，卸载组件释放geometry/material/texture/RAF/监听器。
- **视觉**：至少1080p、1440p、4K及窄窗口截图；浅深主题；地面无穿模，草风一致，水域不漂浮，云不盖住标签；角色有脚下接触及可辨认动作。
- **交互**：点击/拖动/缩放/返回/键盘焦点/切换文件夹；测试桌面遮挡与恢复，帧间delta不导致飞跃。
- **性能**：记录初始化耗时、加载包体、draw calls、三角形、GPU纹理/几何数量、活动及后台帧数；高DPR不能直接无上限使用devicePixelRatio。
- **接收方**：朋友Windows 10实机测试单列；开发机测试通过不等于收件人已验收。
