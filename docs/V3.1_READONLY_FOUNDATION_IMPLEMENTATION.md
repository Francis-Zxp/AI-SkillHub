## 本轮结果

### GitHub 导入可靠性

- 系统 Git、codeload ZIP 与带令牌 API 采用有界降级链。
- ZIP 中的 symlink 只跳过并形成脱敏警告；路径穿越、真实链接落盘、单文件/总量/文件数上限仍阻断。
- 匿名逐 Blob API 回退在发起文件请求前停止，避免天然超过每小时额度。
- 解析 GitHub 403/429 限额信息；失败提示区分网络、限额、仓库和安全检查，不向初学者展示原始命令堆栈。
- `source-import-progress` 事件携带 `operationId`、阶段、状态、消息和可测量字节/文件数；未知大小不伪造百分比。
- `cancel_source_import` 可终止系统 Git、打断 ZIP 流并清理本次隔离暂存目录，不触碰正式技能库。

### MCP 连接中心 P0

- 只读盘点 Codex 用户/Profiles/已登记项目配置，以及 Claude 用户、本地和项目作用域配置。
- 逻辑 Server 与 Host Binding 分开，同名不同目标不会误合并。
- 损坏 TOML/JSON/JSONC 形成 finding，不导致页面崩溃。
- 配置只返回变量名/Header 名和 present/missing/inline 状态，不返回 token/value。
- 静态扫描统一标记 `unprobed`；不执行 `command`、`headersHelper`、OAuth、npm 或任何 MCP Server。

### Codex 插件医生 P0

- 只读检查 Codex home、配置、插件缓存、manifest、hash、link/junction、环境变量覆盖和安装证据。
- 不执行 Codex、PowerShell、JavaScript、npm、`setup.ps1` 或桌面独立修复程序。
- 报告路径和环境信息脱敏；未知版本保持只读且不提供修复按钮。
- 独立桌面工具仍作为 Francis 的重要回滚手段保留，本轮未写入其目录。
