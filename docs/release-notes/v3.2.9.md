# AI SkillHub v3.2.9

日期：2026-10-02。本地候选：签名构建、本机安装与源码推送；不是公开自动更新发布。

## 天空主题（第四套界面风格）

- “天空”成为与经典、现代、活体图谱并列的第四套界面风格：悬浮侧栏、胶囊顶栏、更开阔的页面标题、圆角卡片、实心主按钮的按压反馈与焦点环，切换页面时有轻微的进场动画（开启“减少动态效果”时关闭）。
- 默认“天空 · 随时间变化”：按本机时间在清晨（5–10 点）、正午（10–15 点）、午后（15–19 点）、夜晚之间切换，每分钟检查一次；也可以在主题菜单中固定其中一个时段。
- 去掉原“暮色”主题浑浊的紫褐色与雾感：夜晚改为干净的深蓝，白天各时段使用各自的天空色与强调色。升级后第一次启动会把旧的天空暮色/晴昼主题迁移到“随时间变化”一次。

## 天空岛

- 改为卡通风格：圆润的树、灌木、岩石、草丛、花和蘑菇全部在代码中生成，统一卡通光照（分级明暗）；不再打包写实植物模型和地表贴图，安装包中天空岛素材约 4.5 MB。
- 地表和岩层改为程序化着色：草地色块、踩出的小路、波浪形土层、多面体岩石，没有贴图接缝或重复。
- 新增池塘与瀑布、卡通云海；新增羊、猪、牛、羊驼、巴哥犬、马（Quaternius Farm Animals，CC0）在岛上漫步、走动、跳跃和停顿；保留村民与海鸥。
- 首页可以关掉 3D：天空岛页右上角“简洁分类”切换为不占显卡的分类卡片，设置页“首页 3D 天空岛”同样可以开关。只有软件渲染或没有 WebGL 的电脑默认关闭。
- 渲染开销：动物的分段蒙皮网格在运行时按骨骼与颜色合并，绘制调用大幅减少；帧率上限、暂停、省电、减少动态效果与 WebGL 丢失回退保持不变。

## 星图

- 中心恢复一团柔和的核心光晕；天球外轮廓改为虚线，不再与数据连线混淆。
- 节点按前后深度区分饱和度与亮度：靠前的更亮更饱和，靠后的更淡；前方来源节点有小高光。夜间星图保持冷色。
- 恢复随机流星：每次启动 4–12 颗，大小与轨迹随机。
