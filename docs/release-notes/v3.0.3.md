# AI SkillHub v3.0.3 — Signed Updates and Midnight Prism

v3.0.3 establishes a professional Windows update path and refines the product's
main visual system without moving personal library data back into the program
folder.

## Official Updates

- AI SkillHub checks the official GitHub Release channel automatically.
- A newer version is shown in the top bar and in Settings.
- One click downloads the installer, verifies the mandatory release signature,
  replaces the managed application files, and restarts.
- Sources, Skills, ratings, settings, reports, and SQLite remain in
  `%LOCALAPPDATA%\AI SkillHub\UserData`.
- The primary Windows release is a per-user NSIS installer; a portable zip is
  retained as a fallback.

v3.0.2 and earlier do not contain the updater. Install v3.0.3 once with the
official setup executable; future versions can then be detected in the app.

## Visual Refinement

- Replaced Nocturne Graphite with **Midnight Prism**, a neutral cinematic dark
  system using near-black layers, cobalt and ice hierarchy, and sparse warm
  status accents.
- Renamed **Parchment · Claude-inspired** to **Parchment · Inspiration**.
- Rebuilt the universe nodes: GitHub sources are orbital beacons, parent Skills
  are polygonal route cores, and child Skills are lightweight particles.
- Increased category separation while keeping related nodes in a coherent
  color family.
- Rewrote the homepage line as a concise bilingual product statement:
  “你的 AI 能力，一图掌控。” / “Your AI capabilities, mapped.”

## Release Reliability

- The installer now bundles the four required runtime resources.
- The formal release command signs the installer, writes the updater manifest,
  emits SHA-256 files, builds the portable fallback, and refreshes the
  repository-root developer executable from the exact same binary.
- Formal packaging fails if the configured version and executable version do
  not match.
- Vite scans only the real app entry and ignores unrelated demo HTML in cloned
  source repositories.

## Validation Gate

- React/TypeScript production build.
- Rust tests and Clippy with warnings denied.
- PowerShell parser checks.
- Signed NSIS installer and signature verification.
- Root executable version verification.
- Isolated recipient import and user-data preservation.
- Public asset re-download and checksum verification.
