# AI SkillHub v3.2.17

## 简体中文

- 修复 Windows 安装程序启动失败时，更新器仍隐藏窗口并退出的问题。失败后应用保持可用，可查看提示并重试。
- 安装失败显示安装相关提示，不再统一误报为无法连接更新通道。
- 包含 Claude 桌面 Code 本地运行时、Microsoft Store 版 Claude 检测与 WorkBuddy Skills 投递改进。
- 保留多显示器缩放、窄窗口侧栏和沉浸导航修复。

Windows 安装包没有 Authenticode 发布者签名；更新包仍经过 Tauri 签名验证。智能应用控制可能阻止安装。版本号更新不代表该电脑已获放行；受影响用户可继续使用已验证可安装的 3.2.15。旧版应用内更新使用的是旧更新器，本次退出修复在安装此版后才生效。

## English

- Keep the app open and its resources intact when Windows fails to launch the update installer.
- Show installation-specific failure guidance instead of a misleading update-channel error.
- Include local Claude Desktop Code/Store detection, WorkBuddy Skills delivery, mixed-DPI and compact-navigation improvements.

The Windows binaries are not Authenticode signed. Update packages retain Tauri signature verification. Smart App Control may still block installation; a new version number is not evidence of clearance. Users affected by the block can remain on their working 3.2.15. Updates initiated by older installed versions still use their old updater; this fix takes effect after installing this version.

## 한국어

- Windows에서 업데이트 설치 프로그램을 시작하지 못해도 앱 창과 리소스를 유지합니다.
- 업데이트 채널 오류 대신 설치 실패에 맞는 안내를 표시합니다.
- Claude Desktop Code 및 Store 버전 감지, WorkBuddy Skills 전달, 다중 모니터 배율 및 좁은 창 탐색 개선을 포함합니다.

Windows 바이너리에는 Authenticode 게시자 서명이 없습니다. 업데이트 패키지의 Tauri 서명 검증은 유지됩니다. 스마트 앱 컨트롤이 설치를 차단할 수 있으며, 버전 변경이 허용을 보장하지 않습니다. 차단되는 PC에서는 설치가 확인된 3.2.15를 유지할 수 있습니다. 이전 버전에서 시작한 업데이트는 이전 업데이트 코드를 사용하므로 이 수정은 새 버전 설치 후 적용됩니다.
