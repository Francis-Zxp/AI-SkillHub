# AI SkillHub v3.2.12

本版修复天空岛与星图的运动问题，统一中文字体，并补齐 Origin 桥接的注册与启动入口。

- 云在平移和缩放时不再因噪声种子误差改变轮廓；水潭、溢流弯道与瀑布连成一个连续曲面。
- 动物补齐腿部关节求解，步幅与移动速度对应，落脚阶段保持接地；保留作者毛色，改善受光层次。鸟群加入单飞及不同数量、间距和路线。
- 星图拖动保留稳定名称布局与小数坐标，缓存文字测量；背景繁星在中心可见，向边缘渐隐，屏幕最外缘清空。流星运动与尾迹方向一致。
- 修复高 DPI 鼠标移动的取整误差，以及拖动结束后误选节点。数据球使用统一的右上侧光。
- 内置离线中文 UI 字体，统一各主题文字层级；去掉侧栏重复框线，使首页背景贯穿全窗，并统一上下留白。全屏自动调整场景安全区域。
- Origin 面板区分“文件已部署”和“按钮已注册”，提供“注册并启动 / 启动桥接”，操作前备份，保留当前工程。连接验证兼容作者默认 compact 模式，必须实际 ping 成功才显示可用。

Origin 仍需要有效授权、支持的版本与 Python 环境。首次注册时 Origin 可能显示原生确认窗口；已部署的同版桥接文件可选“全部跳过”。每次新开 Origin 会话都需要启动桥接。

覆盖安装即可保留原技能库、分类、评分和客户端配置。普通来源更新、同名技能共存及配置快照规则不变。

字体来源与许可见 [字体说明](../assets/ui-fonts.md)。详细验收见 [实施记录](../reviews/v3.2.12-implementation-and-validation.md)。
