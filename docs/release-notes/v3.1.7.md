# AI SkillHub v3.1.7

v3.1.7 is a focused regression fix for synchronization results and the Skill
Library source-card layout.

## Synchronization

- Windows PowerShell 5.1 now materializes repository results as a plain array
  before JSON serialization. This prevents the former `Argument types do not
  match` exception at the very end of an otherwise completed sync.
- A partial sync is a completed operation, not an application crash. The UI
  shows updated, failed, and skipped counts from `last-sync.json`.
- Modified or untracked repositories are protected skips. AI SkillHub does not
  overwrite them; commit, back up, or intentionally clean those repositories
  before trying to update them again.
- Network timeouts and diverged branches continue using the current local copy.
  They remain visible in the report for individual follow-up.
- Unexpected script failures show a concise safe message; detailed console
  evidence stays in the local diagnostics bundle.

## Default-window layout

- Source names retain a dedicated minimum column instead of being collapsed by
  popularity, evidence, version, rating, health, enable, and edit controls.
- Metadata wraps inside a shrinkable column, and container queries stack it
  below the name on narrow source cards.
- Verified at 1920×1271, 1536×900, and 1280×820 with no header overflow or
  browser console error.
