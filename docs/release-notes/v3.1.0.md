# AI SkillHub v3.1.0

v3.1.0 is the reliable-import and read-only connection-diagnostics release.

## Highlights

- Real backend import stages replace simulated percentage progress.
- Cancel stops the owned Windows process tree, removes partial staging and
  never changes formal sources.
- The built-in GitHub ZIP path skips symlink aliases without following or
  creating them, while retaining real `SKILL.md` directories.
- Anonymous per-blob API fallback is refused before it can exhaust GitHub's
  public-IP quota.
- The new MCP Connection Center inventories existing Codex and Claude Code
  bindings without starting servers or returning secret values.
- The new Codex Plugin Doctor is strictly read-only and reports zero mutations;
  it never invokes the separate desktop repair utility or repository scripts.

## Release gates

- Production frontend build and v3.0.7/v3.1 behavior contracts.
- Complete Windows Rust unit suite plus MCP and Codex-doctor integration suites.
- Deterministic running-import cancellation with a five-second upper bound.
- Real isolated codeload import of
  `Imbad0202/academic-research-skills`, including symlink skipping and per-file
  security scanning.
- Fresh-recipient portable test, signed NSIS install/upgrade data-preservation
  test and clean `windows-latest` CI are required before publishing the tag.
- Chrome visual QA includes an 860 CSS px high-DPI desktop window and verifies
  the complete topbar remains within its right and bottom edges.

## Deliberate boundary

This release does not write MCP configurations, manage OAuth or tokens, start
unknown MCP servers, or repair plugins. The standalone Codex health utility is
unchanged.
