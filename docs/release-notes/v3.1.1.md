# AI SkillHub v3.1.1

v3.1.1 is an urgent formal-desktop import hotfix.

## Fixed

- The signed v3.1.0 desktop package could reject the new live import-progress
  subscription with `Command plugin:event|listen not allowed by ACL` before
  GitHub download began.
- The main window now receives only `core:event:allow-listen` and
  `core:event:allow-unlisten`. Frontend event emission remains unavailable.
- Progress subscription is now fail-soft. If listening is unavailable, the
  staging command still runs and import continues without live progress.

## Unchanged safety boundaries

- GitHub content is still downloaded into isolated staging, bounded and scanned
  before promotion.
- Archive symbolic links are skipped without following or materializing them.
- Cancellation still terminates the owned Windows process tree and removes the
  incomplete staging directory.
- MCP Connection Center and Codex Plugin Doctor remain strictly read-only.

## Release gate

The hotfix requires a real packaged WebView ACL check, a signed v3.1.0 to v3.1.1
upgrade/data-preservation test, an isolated recipient import and a second-computer
import acceptance before the release is considered complete.
