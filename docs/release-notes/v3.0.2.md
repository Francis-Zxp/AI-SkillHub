# AI SkillHub v3.0.2 — Persistent Data, Automatic Routing, and Theme Refresh

v3.0.2 completes the recipient-computer fixes and makes upgrades safe for an
existing personal Skill library.

## Highlights

- Parent Skill ratings are now stored on the source itself, so they remain
  visible even when a generated parent-router file has not been indexed yet.
- ChatGPT Desktop and OpenAI Codex are detected with separate desktop and code
  capability signals. The app recognizes the MSIX/Start app, a running desktop
  process, common desktop install paths, Codex CLI, bundled Codex binaries, and
  real Codex state.
- Sources, Skills, ratings, configuration, reports, and SQLite state now live
  in `%LOCALAPPDATA%\AI SkillHub\UserData`. Installing or extracting a newer
  application build no longer replaces personal data.
- First launch performs a copy-only migration from the v3.0.1 portable data
  folders. The old folders are retained until the user chooses to remove them.
- Exact same-name child Skill collisions are automatically assigned using
  enabled state, health, personal rating, and path specificity. Every candidate
  keeps a source-qualified alias, and a manual override remains available.

## UI and Theme Changes

- Added **Nocturne Graphite**, the new default neutral dark theme with restrained
  blue, ivory, and gold accents.
- Added **Parchment**, a Claude-inspired reading theme with warm paper surfaces,
  ink text, clay accents, and muted sage status colors.
- Rebuilt the Settings theme selector as a compact visual grid.
- Increased Routing Observatory typography and made it obey the global text
  scale.
- Reduced the top sync icon to the same optical size as nearby controls and
  shortened AI-tool detection copy.
- Replaced the Classic star map's radial wash with a clean grouped field.
- Bar charts now omit zero-only rows and show an honest empty state when no
  comparable activity or popularity data exists.
- Generated parent routers are no longer repeated as unassigned standalone
  Skills in browser preview or source grouping.

## Upgrade

1. Download `AI-SkillHub-3.0.2.zip`.
2. Extract it to a new folder or replace the old program files.
3. Start `AI SkillHub.exe`.
4. The app reuses `%LOCALAPPDATA%\AI SkillHub\UserData` automatically.

Do not copy the old `app-next\data`, `app-next\.skillhub-next`, or `skills`
folders into the new package. v3.0.2 migrates them on first launch when needed.
