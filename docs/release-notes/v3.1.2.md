# AI SkillHub v3.1.2

v3.1.2 fixes large-source security review and Add Source draft loss.

## Fixed

- Script files are counted as an inventory instead of producing one duplicate
  finding per file.
- Multi-keyword detections must occur on the same line.
- Commands shown in documentation, examples, tests, fixtures and imported
  GitHub workflows require explicit review instead of blocking the entire
  source. AI SkillHub never executes those files during import.
- Dangerous commands in operational scripts and `SKILL.md` remain high-risk
  blockers.
- Add Source fields survive page navigation and app restarts. Transient import
  state and prior security confirmations are never persisted.

## User flow

When a large repository contains reviewable content, AI SkillHub keeps it in
the isolated staging area, shows the evidence, and waits for an explicit user
confirmation. Nothing is written to the managed Skill Library before that
confirmation.

The release gate uses the real
`Imbad0202/academic-research-skills-codex` repository through the built-in
codeload fallback and verifies that reviewable examples do not become a false
whole-repository block.
