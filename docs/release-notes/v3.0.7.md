# AI SkillHub v3.0.7

v3.0.7 is a focused visual-integrity and state-semantics release.

## What changed

- Skill/source editing now inherits the active theme and remains readable in
  all ten bundled themes.
- The capability atlas uses one geometrically centered volumetric core.
- Space motion uses 5–20 bounded, session-stable meteors with randomized size,
  direction, opacity and speed; reduced-motion and adaptive LOD still win.
- Startup says `加载本地索引` / `Loading local index` while reading local
  SQLite/cache data. It does not claim a Git or AI-tool synchronization.
- The homepage can enter an immersive graph-only layout and exit through the
  visible control or `Escape`.
- A GitHub icon opens the official AI SkillHub project through a narrowly
  allowlisted desktop capability.

## Data and update safety

The signed NSIS updater replaces only managed application files. Existing
sources, ratings, tags, settings, reports and SQLite data remain under:

```text
%LOCALAPPDATA%\AI SkillHub\UserData
```

The updater accepts only installers signed by the AI SkillHub updater key.
