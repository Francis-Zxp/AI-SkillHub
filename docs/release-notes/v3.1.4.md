# AI SkillHub v3.1.4

v3.1.4 is a reliability release for the signed desktop updater.

## Fixed

- Replaced the single manifest endpoint with three ordered, signed metadata
  channels: GitHub Releases, Raw GitHub, and jsDelivr.
- Added current-version query parameters and no-cache headers to reduce stale
  `releases/latest` and CDN responses immediately after publishing.
- Serialized update checks and installs so startup checks, manual clicks, and
  reconnect events cannot race or overwrite each other's state.
- Added safe categories for network, timeout, TLS, proxy, manifest, signature,
  permission, download, and install failures. Raw transport messages are never
  written to the UI or local storage.
- Added background retries, online-event recovery, and a throttled resume check.
- Increased signed installer download timeout from two minutes to ten minutes.
- Added an exact allowlisted link to the official GitHub Releases page as a
  manual fallback. No user-controlled URL is passed to the opener.
- Added a public update-channel health probe and regression contracts for
  redundant endpoints, retry bounds, diagnostics, and concurrency guards.

## Safety and data

The updater still accepts only the existing AI SkillHub minisign public key.
Program files are replaced by the signed NSIS installer; sources, ratings,
settings, SQLite state, and reports remain in the independent user-data folder.
A failed check, download, or install does not remove the current version.

## Known boundary

The three metadata channels improve release discovery. The signed Windows
installer is still hosted in the official GitHub Release, so a network that
blocks every GitHub release-asset domain must use the same official release page
from a reachable connection. AI SkillHub does not weaken signature verification
or accept an unsigned third-party binary mirror.
