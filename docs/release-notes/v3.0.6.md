# AI SkillHub v3.0.6 — Resilient updates and cache-first live atlas

v3.0.6 is a focused reliability and visual-polish release. It recovers from
short GitHub release-propagation delays without an app restart, restores Skill
editing to a viewport-level glass drawer, and returns the capability atlas to a
single volumetric center while preserving the responsive v3.0.5 interaction.

## Highlights

- Manual update checks try the signed official channel up to three times with
  short backoff. A persistent transient failure schedules two bounded background
  checks (45 seconds and 120 seconds) instead of requiring a restart.
- Source and Skill editors render through a document-level portal. Their fixed
  520 px glass drawer stays 12 px from the top, right and bottom of the desktop
  viewport and remains above the navigation rail.
- The visible artwork inside the transparent logo PNG is optically centered;
  the collapsed rail no longer reserves a hidden text column.
- Theme names remain on one line across desktop and narrow window layouts.
- The atlas restores a bounded cache of the previous real node/edge model on
  startup and then crossfades to the current SQLite snapshot. This is local
  index hydration, not a fake Git/source synchronization.
- The visual field uses one directional volumetric core. Decorative dust and
  shell points are quieter, while meteors receive a random count, length,
  direction and speed once per app session and remain stable during that
  session.

## Upgrade and data safety

Users on v3.0.3 or newer can install v3.0.6 through the signed in-app updater.
Only managed program files are replaced. Sources, ratings, tags, notes,
settings, audit history and SQLite remain under:

```text
%LOCALAPPDATA%\AI SkillHub\UserData
```

The graph startup cache contains only bounded visualization nodes, edges,
display labels, counts and layout data. It excludes absolute source paths,
free-form notes and full source/Skill records.
