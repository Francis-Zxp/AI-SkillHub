# AI SkillHub v3.1.3

v3.1.3 fixes imports from very large GitHub repositories without weakening the
existing security boundary.

## Fixed

- GitHub imports now begin with a partial clone and repository-tree discovery.
- Only directories rooted at a real `SKILL.md` are checked out for installation.
- Repositories without a Skill keep only root Markdown reference material.
- If system Git and the full codeload archive fail, AI SkillHub can use the
  repository author's latest explicitly named Skill ZIP release asset.
- Release assets must belong to the same repository, contain `skill` in the
  filename, use ZIP format, and remain within the bounded download limit.
- Large self-contained template and icon libraries can contain up to 20,000
  files; the 80 MB total-content and 16 MB single-file limits remain enforced.

## Verified repository

Both download paths were tested against `hugohe3/ppt-master`:

- sparse Git checkout: one Skill, about 12,351 files and 66.3 MB;
- official `ppt-master-skill-v4.4.0.zip` Release asset: one Skill and more than
  10,000 files scanned;
- unrelated root `examples` content was not imported;
- the resulting Skill-only tree passed the security promotion gate.

User sources, ratings, tags, settings and the SQLite index remain in the stable
per-user data directory during an in-place update.
