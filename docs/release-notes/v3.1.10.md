# AI SkillHub v3.1.10

v3.1.10 makes reviewed source imports practical, folder organization responsive,
and parent Skills easier to recognize in Codex and Claude.

## Highlights

- A repository with review findings can be added to local management after explicit
  confirmation. It is forced disabled and is not delivered to any AI tool until the
  user enables it.
- The scanner no longer mistakes a fixed `/tmp/...` cleanup for a root deletion.
  Dangerous examples under references, documentation and tests remain visible for
  review without blocking the whole parent repository.
- Clicking or using Enter/Space on a parent source's Move control opens its folder
  selector; drag-and-drop still moves the complete parent/child tree.
- Folder cards use one non-overlapping management action. Rename, color, order and
  delete controls live in the editor, and folder commands no longer reload the full
  Skill catalog after each change.
- Generated parent descriptions use `◈ 父 · N 个子项 · up to five capabilities`.
  The hidden ASCII `[ROUTER-HUB]` marker remains the machine-recognition contract.

## Safety

Source scanning never executes repository scripts. Content review can authorize
local storage only; path containment, scan-limit and archive safety blockers remain
fail-closed. Deleting a user folder never deletes Skills or author repositories.
