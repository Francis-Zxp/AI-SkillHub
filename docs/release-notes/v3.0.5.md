# AI SkillHub v3.0.5 — Responsive imports and source-scoped routing

v3.0.5 fixes the large-repository import freeze, makes parent routing
source-safe, and finishes the 3.x visual and layout pass.

中文摘要：导入 GitHub、本地目录或压缩包时，预览、下载、安全扫描和正式
写入均转入后台工作线程，界面持续显示五阶段进度，不再阻塞桌面操作。
内置 GitHub 下载器在 80 MB、单文件 16 MB 和逐文件安全扫描不变的前提
下，支持最多 6000 个筛选文件；`pbakaus/impeccable` 的真实隔离下载与
安全扫描门禁已通过。

## Highlights

- Source preview, staging, security scanning, promotion and Agent-link refresh
  no longer run on the WebView event thread. The import wizard shows an
  accessible five-stage progress indicator throughout the operation.
- The bounded fallback downloader now supports legitimate multi-provider Skill
  repositories above the old 1500-file cap while retaining path traversal,
  symlink, file-size, archive-size and per-file security gates.
- Generated parent Skills contain explicit source-scoped child paths. Automatic
  routing never substitutes an exact same-name child from another source.
  Source-qualified aliases remain available; only an explicit advanced choice
  creates a global bare-name dispatcher.
- The non-deploying Preset/workspace distribution matrix is removed from the
  product UI. Existing SQLite rows remain untouched for backward compatibility.
- Maintenance tools are closed by default and remain an advanced inspection
  surface.
- Spectral Gravity gains fuller layered atmosphere, glossy circular source and
  parent nodes, subtle deterministic meteors, smoother inertia, and unrestricted
  horizontal and vertical rotation.
- The current Deep Space and Mist themes remain available. Two additional
  Classic Deep Space / Classic Mist themes restore the original v3.0.2 color
  tokens without replacing current user preferences.
- Theme names and sun/moon icons are consistent. Sidebar logo centering,
  topbar/content/touchbar axes, responsive page headers and natural text wrapping
  are verified at the default 1280×820 window.

## Upgrade and data safety

Users on v3.0.3 or newer receive v3.0.5 through the signed in-app updater.
Only managed program files are replaced. Sources, ratings, tags, notes,
settings, audit history and SQLite remain under:

```text
%LOCALAPPDATA%\AI SkillHub\UserData
```

The update package is accepted only after the embedded Tauri updater public key
verifies its signature.
