# AI SkillHub v3.1.9

v3.1.9 makes parent Skill management clearer without exposing internal routing
tokens or removing useful personal controls.

## Highlights

- Parent/source cards once again have a persistent five-star personal rating.
- Long parent names can use two lines, and the full name remains available on hover.
- The folder drag control is now a labeled six-dot grip that moves the complete
  parent/child tree; the folder dropdown provides the same result without dragging.
- Agent-visible descriptions use the concise `父 Skill` label. The ASCII
  `[ROUTER-HUB]` token remains in a hidden comment for reliable machine detection.
- Codex Plugin Doctor can reveal every bounded evidence item and copy a redacted
  diagnosis. MCP Connection Center keeps a valid selection after rescans, shows
  host-level findings and copies only redacted configuration paths.

## Safety

Both diagnostic centers remain read-only. They do not start MCP servers, execute
plugin code, read secret values, run PowerShell repair scripts or modify config.
