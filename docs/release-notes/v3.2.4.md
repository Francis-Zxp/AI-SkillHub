# AI SkillHub v3.2.4

## 中文说明

v3.2.4 是 v3.2.3 的正式补丁版，新增「一键安装 Git」，界面布局、操作流程和安全边界保持不变。

- **设置页新增 Git 运行时卡片。** 检测到本机没有 Git 时，卡片会说明装上 Git 的好处 —— 更新从「重新下载整个快照」变成增量拉取、覆盖前能识别出你自己改过的文件、私有仓库也需要它 —— 并提供「一键安装 Git」按钮。
- 一键安装调用 Windows 自带的程序包管理器：`winget install --id Git.Git`，来源是微软官方包仓库。系统太旧没有 winget 时，卡片改为提示无法一键安装，并提供「打开官方下载页」按钮。
- 已经装了 Git 的电脑只会看到一行确认信息，显示检测到的版本。

### 安全边界

软件**不内置任何 Git 二进制文件，也不自己下载安装程序** —— 由 winget 从它自己的官方源解析 `Git.Git`。安装过程非交互执行，最长等待 10 分钟。如果 winget 报告成功但当前进程的 PATH 还读不到 Git，会明确提示「需要重启 AI SkillHub」，而不是谎报成功或失败。

### 说明

没有 Git 也能同步 —— 这是 v3.2.3 已经解决的问题。这个功能的定位是「装了更快更安全」，不是「不装就用不了」。

## English

v3.2.4 is the formal patch release for v3.2.3. It adds one-click Git installation and preserves the existing layout, workflows, and safety boundary.

- **Settings now has a Git runtime card.** On a machine without Git it explains what Git buys — incremental pulls instead of re-downloading a whole snapshot, local-edit detection before an overwrite, and access to private repositories — and offers a one-click install.
- The install runs `winget install --id Git.Git` against the official Microsoft package manager. Windows builds without winget get a button that opens the official git-scm.com download page instead.
- When Git is already present, the card simply confirms the detected version.

### Safety boundary

The app **bundles no Git binary and downloads no installer itself**; winget resolves the official `Git.Git` package from its own source. The install runs non-interactively with a 10-minute ceiling. A winget success that the running process cannot yet see on PATH is reported as "restart required" rather than as either success or failure.

### Note

Sources already sync without Git — that was fixed in v3.2.3. This feature makes updates faster and safer; it is not a prerequisite.

## Release boundary

The fallback updater manifest is published only after signed assets are uploaded, anonymously downloaded, hash-compared, and verified with the embedded updater key.
