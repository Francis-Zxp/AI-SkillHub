# AI SkillHub v3.1.11

v3.1.11 fixes source synchronization, makes folder organization responsive, and
gives Prompt repositories an honest Codex/Claude invocation workflow.

## Highlights

- Fixes `InvokeMethodOnNull` after an empty library wrote a zero-byte
  `managed-links.json`. Empty and damaged legacy state now recovers safely under
  both Windows PowerShell 5.1 and PowerShell 7.
- Publishes generated parent routers before reconciling active Skills, removes
  stale managed junctions whose target no longer contains `SKILL.md`, and never
  resurrects those entries as healthy Skills in diagnostics. Router write errors
  fail closed before any new active catalog is delivered.
- Reflows user folders into a responsive grid. The edit action lives inside the
  upper-right corner of each card, titles and counts stay readable, and the
  native horizontal scrollbar is gone.
- Keeps Prompt repositories separate from Skills. A Prompt source now offers
  “Prepare invocation”, a bounded copy payload, Codex/Claude readiness, and an
  option to open its managed project directory. It does not invent `/name` or
  `@name` commands.
- New Prompt imports preserve their complete bounded project workspace, including
  files such as `train.py` and `prepare.py`, then apply the existing content scan.
- MCP parse/read failures remain visible even when no server binding could be
  created. Codex Plugin Doctor copy now includes every bounded, redacted evidence
  section while remaining read-only.

## Safety and compatibility

- Git repositories with local modifications remain protected skips; pull failures
  and timeouts report partial completion without removing local sources.
- Prompt workspaces remain capped at 20,000 files, 16 MB per file, 80 MB total,
  and ten directory levels. Boundary violations fail closed.
- Git tree size is checked before a complete Prompt checkout; LFS smudge and
  external filters are disabled so an upstream cannot bypass the preflight.
- Folder deletion removes only local classification metadata. Prompt sources are
  never installed into a Skills directory without a real `SKILL.md`.
