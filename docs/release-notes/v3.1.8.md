# AI SkillHub v3.1.8

v3.1.8 makes the parent Skill the single management and invocation unit.

## Highlights

- Every non-empty source now receives one canonical `[ROUTER-HUB]`, including
  single-child projects such as `figures4papers`.
- Same-name child Skills are isolated by parent source. Manual global conflict
  selection and generated conflict dispatchers are removed from the workflow.
- Codex, Claude and Antigravity receive the same curated parent-first catalog.
- Parent descriptions list child capabilities and exact source-scoped paths.
- Skill Library cards focus on names, purpose, folder, health and enabled state;
  evidence scores and raw revisions no longer crowd the primary surface.
- Skill descriptions follow the selected UI language using offline summaries;
  author files and original descriptions remain untouched.

## Upgrade safety

Generated files are replaced recoverably, user-owned Agent folders are
preserved, and existing data remains under the stable UserData directory.
