# AI SkillHub v3.2.16

## 简体中文

- 修复普通安装及 Microsoft Store 版 Claude Desktop 内置 Code 引擎的识别；没有全局 CLI 的电脑也能连接本地 Code Skills。
- 修复多显示器缩放时的天空岛渲染尺寸、窄窗口侧栏按钮横排和多余滑杆。
- 群岛与星图进入应用内全屏后，切换按钮和退出按钮统一对齐。
- 新增 WorkBuddy 代码开发会话的本地 Skills 投递与扫描，保留用户原有 Skills。实际 WorkBuddy 宿主调用尚待装机验收。

### Claude 桌面端怎么试

1. 更新 AI SkillHub；打开 Claude Desktop 的 **Code**，选择 **Local（本机 Windows）**并打开一个项目，等待内置引擎完成初始化。
2. 在 AI SkillHub「AI 工具」检测并连接 Claude，完成 Skills 同步。
3. 在 Claude Code 新建本地会话，输入 `/` 搜索父 Skill 的项目名。

本版处理本机 Windows Code 的目录投递。Chat/Cowork 使用账户中的自定义技能；Cloud、SSH、WSL 不读取这份 Windows 用户目录。安装第三方 Skill 不会自动安装其所需的 Python、软件或外部服务。若仍未显示，请附上 AI SkillHub 诊断报告及 Claude 的版本、会话环境。

## English

- Detect the embedded local Code engine in both regular and Microsoft Store installations of Claude Desktop, without requiring a global CLI.
- Fix mixed-DPI island rendering, narrow-window navigation, unwanted scrollbars and fullscreen control alignment.
- Add local Skills delivery and discovery for WorkBuddy code-development sessions; preserve existing user Skills. WorkBuddy host invocation still needs acceptance on an installed client.

For Claude Desktop, initialize **Code → Local** on Windows, connect and sync Claude in AI SkillHub, then open a new local Code session and find the parent Skill with `/`. Chat/Cowork account Skills and Cloud/SSH/WSL environments use different locations. Dependencies required by third-party Skills must still be installed separately.

## 한국어

- 일반 설치 및 Microsoft Store Claude Desktop의 내장 로컬 Code 엔진을 인식합니다. 전역 CLI를 별도로 설치할 필요가 없습니다.
- 다중 모니터 배율 변경, 좁은 창의 탐색 버튼 배치, 불필요한 스크롤바와 전체 화면 버튼 정렬을 수정했습니다.
- WorkBuddy 코드 개발 세션의 로컬 Skills 전달 및 검색을 추가하고 기존 사용자 Skills를 보존합니다. 실제 WorkBuddy 호출은 설치된 클라이언트에서 추가 검증이 필요합니다.

Claude Desktop에서 Windows **Code → Local**을 먼저 초기화한 뒤 AI SkillHub에서 Claude를 연결·동기화하세요. 새 로컬 Code 세션에서 `/`로 부모 Skill을 찾을 수 있습니다. Chat/Cowork 및 Cloud/SSH/WSL 환경은 별도 경로를 사용하며, 개별 Skill의 실행 의존성은 따로 설치해야 합니다.
