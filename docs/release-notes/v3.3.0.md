# AI SkillHub v3.3.0

日期：2026-10-08。本地候选版本：签名构建，在本机安装。不是公开的自动更新发布。

## 一键接管，更少操作

- 新的侧栏和顶栏：
  - 侧栏显示文字，AI 工具各列一行，带数量。
  - 搜索支持 Ctrl/⌘+K。
  - 任何页面都能点"+ 添加"，或者直接粘贴：GitHub 地址、owner/repo、/tree/ 子路径、本地文件夹、.zip 都认，粘贴 MCP 配置也行。
  - 顶栏只留"更新 (N)"和一个同步状态点。
- 全面改用通俗说法：技能、技能包、MCP、AI 工具。去掉了不起作用的"真实写入授权"药丸和空壳的工作区页。
- 首次运行先引导，征得同意前不往任何 AI 工具目录写入。
- 每个 AI 工具都有"接管"开关，另有"暂停同步到 AI 工具"，这两个都由后端真正执行。老用户升级后，已在用的工具保持接管。

## 布局（按试用反馈调整）

- 首页回到 3.2.x 的布局：场景铺满页面，四个数字放在底部栏，不会挡住数据球；首页场景可选 群岛 / 星图 / 归纳，"归纳"就是分类聚类视图。
- 左侧改回细长的图标条；语言、主题和 GitHub 按钮回到顶栏。
- 删除了两个现代主题和两个经典主题，设置里直接列出全部主题。
- 技能库每行先显示你的备注，并在行上直接提供"复制调用名"。复制出来的是 AI 工具能识别的名字：父入口名，或"父入口 子技能名"。
- ⋯ 菜单不会再被卡片挡住。

## 界面细节（第二轮试用反馈）

- 整体换成液态玻璃质感：顶栏、侧栏、底部栏和场景按钮是半透明玻璃，带高光边缘和柔和阴影；大块玻璃的边缘会轻微折射后面的画面。显卡较弱或系统开了"减少透明度"时自动关掉折射。
- 首页的"群岛 / 星图 / 归纳"和右侧的场景按钮、全屏按钮排成一行，高度、样式一致；选中项是一颗会滑动的玻璃珠。
- 全屏时底部栏恢复成旧版的小尺寸，居中显示，不再横贯整个窗口。
- 简洁分类里的卡片大小一致；占比条下面有一条完整的轨道。
- 进度条只用当前主题的主色。
- 技能库：名字后面就是"复制调用名"按钮，备注和简介放在第二行；你自己的分组排在前面，"全部 / 未归档"放在最右边；去掉了 Codex 后面的链接图标（共用文件夹写在悬停提示里）；停用或待确认安全的技能包会直接写明，点一下就能去启用。
- 天气可以叠加：彩虹、极光、多云、起雾能和任何天气同时出现；小雨、雷雨、下雪、落花同一时间只能选一种。
- 彩虹改成连续的光谱，边缘柔和，外面还有一道淡淡的副虹。
- 星图的光晕放在数据球中心，球体更有立体感。
- 动物不再"顺拐"（同侧的腿一起迈）；岛屿边缘不再翘起。
- Codex 自带的 MCP（例如 node_repl）只在 Codex 里可用，其他工具里显示"不支持"，也不再误报"需要 API Key"。
- 归纳视图的技能数和技能库一致（技能包自动生成的入口不算一个技能）。
- 面板质感可以在"设置 → 外观"里切换：磨砂玻璃（默认，3.2 的样子）或液态玻璃。
- 修复 Codex 里同一个技能出现多次：旧版本把接管前的备份放进了技能目录里，现在会挪到旁边。
- 星图只保留球心的光；顶栏图标大小统一。

## 技能

- 每个技能包一排 AI 工具图标，点一下就能同步到某个工具，或从它移除。图标状态以读回磁盘的结果为准。
- 同步改为后台合并执行，不再锁住整个窗口。
- 关掉子技能后，它也会从父入口里移除。
- 导入只需要一个输入框：
  - 自动预览包含的技能、安全检查结果和要同步到的工具。
  - 被安全审查标记的技能包，仍然只能"仅加入技能库（保持停用）"。
- 本机已有的技能可以一次全部纳入管理。
- Cursor 和 Gemini CLI 作为实验性目标，默认关闭。
- 同名的个人目录只报告为冲突，不再移走。

## MCP

- "MCP × AI 工具"矩阵，覆盖 Codex、Claude Code、Claude Desktop、Cursor：每个格子点一下即可启用或停用，列头可以"启用其余 N 个"。
- 可以直接粘贴 README 里的配置（JSON、TOML、VS Code、OpenCode 格式），也有常用模板和"发现"页。
- API Key 在软件里填写，存成用户环境变量，配置里只写引用。
- 测试连接由你点击后才运行，先显示要运行的命令，只握手并列出工具。
- 每个工具单独报告结果，可以撤销，历史记录写成人话。
- 写入前快照、指纹比对、原子写入、写后回读，全部照旧。

## 天空岛

- 八种随机地形气候：草甸、雪山、沙漠台地、热带、秋林、火山、晶石、梯田。
- 九种天气，可在"世界"面板里换一个世界，或固定天气。
- 修复多处视觉问题，绘制调用大幅减少。

## 内存

- 最小化或长时间在后台时，隐藏 WebView 并降低内存目标。
- 3D 场景看不见时休眠，换成一张静态图。
- 去掉每帧产生的临时对象；网络服务改在 WebView2 主进程里运行；缩小 V8 的年轻代。
- 隔离环境实测：最小化时约 20 MB（原来约 330 MB）。

验证与边界见 docs/reviews/v3.3.0-implementation-and-validation.md。公共更新清单不变。
