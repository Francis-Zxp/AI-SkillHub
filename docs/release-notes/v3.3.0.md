# AI SkillHub v3.3.0

日期：2026-10-08。本地候选版本：签名构建，在本机安装。不是公开的自动更新发布。

## 一键接管，更少操作

- 新的侧栏和顶栏：
  - 侧栏显示文字，AI 工具各列一行，带数量。
  - 搜索支持 Ctrl/⌘+K。
  - 任何页面都能点"+ 添加"，或者直接粘贴：GitHub 地址、owner/repo、/tree/ 子路径、本地文件夹、.zip 都认，粘贴 MCP 配置也行。
  - 顶栏只留"更新 (N)"和一个同步状态点。
- 全面改用通俗说法：技能、技能包、MCP、AI 工具。去掉了不起作用的"真实写入授权"药丸和空壳的工作区页。
- 首次运行先引导，征得同意前不往任何 AI 工具目录写入。
- 每个 AI 工具都有"接管"开关，另有"暂停同步到 AI 工具"，这两个都由后端真正执行。老用户升级后，已在用的工具保持接管。

## 技能

- 每个技能包一排 AI 工具图标，点一下就能同步到某个工具，或从它移除。图标状态以读回磁盘的结果为准。
- 同步改为后台合并执行，不再锁住整个窗口。
- 关掉子技能后，它也会从父入口里移除。
- 导入只需要一个输入框：
  - 自动预览包含的技能、安全检查结果和要同步到的工具。
  - 被安全审查标记的技能包，仍然只能"仅加入技能库（保持停用）"。
- 本机已有的技能可以一次全部纳入管理。
- Cursor 和 Gemini CLI 作为实验性目标，默认关闭。
- 同名的个人目录只报告为冲突，不再移走。

## MCP

- "MCP × AI 工具"矩阵，覆盖 Codex、Claude Code、Claude Desktop、Cursor：每个格子点一下即可启用或停用，列头可以"启用其余 N 个"。
- 可以直接粘贴 README 里的配置（JSON、TOML、VS Code、OpenCode 格式），也有常用模板和"发现"页。
- API Key 在软件里填写，存成用户环境变量，配置里只写引用。
- 测试连接由你点击后才运行，先显示要运行的命令，只握手并列出工具。
- 每个工具单独报告结果，可以撤销，历史记录写成人话。
- 写入前快照、指纹比对、原子写入、写后回读，全部照旧。

## 天空岛

- 八种随机地形气候：草甸、雪山、沙漠台地、热带、秋林、火山、晶石、梯田。
- 九种天气，可在"世界"面板里换一个世界，或固定天气。
- 修复多处视觉问题，绘制调用大幅减少。

## 内存

- 最小化或长时间在后台时，隐藏 WebView 并降低内存目标。
- 3D 场景看不见时休眠，换成一张静态图。
- 去掉每帧产生的临时对象；网络服务改在 WebView2 主进程里运行；缩小 V8 的年轻代。
- 隔离环境实测：最小化时约 20 MB（原来约 330 MB）。

验证与边界见 docs/reviews/v3.3.0-implementation-and-validation.md。公共更新清单不变。
