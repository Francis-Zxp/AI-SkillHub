# AI SkillHub v3.2.18

## 中文

- 修复 WorkBuddy AI 自定义安装路径识别，按已装版本选择正确的 Skills 目录。
- 扣子自动使用默认 `.agents/skills` 扫描目录，保留个人技能和旧路径，避免重复扫描。添加到云端 Agent 后，用户已确认可通过 `/` 调用。
- 完整探测已列出的 14 个 AI 工具，区分“已安装”“发现技能”和“已连接”。
- 修复 Codex 插件医生的版本识别与缓存扫描误报，检查保持只读。

**扣子首次使用：** 开启本地文件访问，在云端 Agent 对话选择 **＋ → 技能 → 从个人设备添加技能**，添加后用 `/` 的技能页签调用。默认扫描目录无需手动添加；如果曾删除默认目录，请在扣子恢复默认。

## English

- WorkBuddy AI: detect custom installation locations and the current executable name. Read the installed product metadata to select the correct user Skills directory, including `.workbuddy-ai/skills` in 5.6.2.
- AI tools: perform actual probes for all listed tools and distinguish installation, local Skills discovery, and automatic delivery.
- Coze desktop: detect installation and automatically prepare real Skill entries in its default `.agents/skills` scan directory. Preserve personal Skills; migrate only SkillHub-owned links. Retain old catalog paths as aliases, with backups, to avoid duplicate scan entries.
- Coze conversations: clearly distinguish scanned Skills from Skills added to a cloud Agent. The `/` menu only searches added Skills; use `+ → Skills → Add from personal device` in Coze. File-access permission and the choice of Agent remain in Coze.
- Sync status: personal Skills and unrelated links no longer appear as already managed by SkillHub.
- Codex plugin doctor: recognize registered Windows desktop versions and avoid treating runtime dependency trees as plugin inventory. Checks remain read-only.

Reopen WorkBuddy's Skills list after synchronizing. Detection and delivery checks do not constitute a model invocation test.

## 한국어

- WorkBuddy AI의 사용자 지정 설치 경로를 감지하고 설치된 버전에 맞는 Skills 폴더를 선택합니다.
- Coze 기본 `.agents/skills` 폴더에 스캔 가능한 항목을 자동으로 준비합니다. 개인 파일과 기존 경로를 보존하고 중복 검색을 방지합니다.
- Coze 클라우드 Agent에서 **＋ → 스킬 → 개인 기기에서 스킬 추가**로 등록한 후 `/`로 호출합니다. 사용자가 이 흐름의 성공을 확인했습니다.
- 등록된 14개 AI 도구의 설치, 스킬 발견, 연결 상태를 구분하고 Codex 플러그인 진단의 버전 감지와 캐시 탐색을 개선했습니다.
