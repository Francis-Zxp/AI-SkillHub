# AI SkillHub v3.2.1

## 中文说明

v3.2.1 是 v3.2.0 的正式补丁版，不改变既有界面、操作流程或 MCP 安全边界。

- 首页前台可见时，数据球恢复缓慢旋转；离开首页、窗口失焦、页面隐藏或启用“减少动态效果”时不再绘制，拖动和缩放时仍会即时提升到流畅帧率。
- MCP 连接中心会静态盘点 Claude Code 已知项目及其项目根目录 `.mcp.json` 中的连接，因此不必先在 AI SkillHub 登记项目才可查看。未登记项目只显示脱敏来源且保持只读，不能由 AI SkillHub 修改。
- 不会启动 MCP Server，不会执行 `claude mcp list`，也不会读取或显示凭据值。会话临时配置、其他操作系统或其他用户配置仍需在对应环境中保存为标准 Claude Code 配置后才能被发现。

## English

v3.2.1 is the formal patch release for v3.2.0. It preserves the existing interface, workflows, and MCP safety boundaries.

- The dashboard data ball rotates slowly only while the focused homepage is visible. It does not draw on other pages, while unfocused or hidden, or when reduced motion is enabled; drag and zoom still wake smooth interaction rendering.
- The MCP centre statically inventories bounded known Claude Code projects and safe project-root `.mcp.json` files. Projects not managed by AI SkillHub remain redacted and read-only.
- AI SkillHub never starts an MCP server, runs no Claude runtime command, and never reads or displays credential values. Temporary-session, other-OS, or other-user settings need a persisted standard Claude Code configuration in that environment before they can be discovered.

## Release boundary

The fallback updater manifest is published only after the signed release assets have been uploaded, anonymously downloaded, hash-compared, and verified with the embedded updater key.
