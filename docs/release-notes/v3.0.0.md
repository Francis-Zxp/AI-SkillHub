# AI SkillHub v3.0.0 — Living Atlas

AI SkillHub 3.0 turns the dashboard into a living map of the capability library
while keeping the operational pages practical and readable.

## Highlights

- The homepage is now a real-data Skill universe, not a decorative animation.
  Sources, parent Skills, and child Skills form an interactive relationship
  globe driven by the local index.
- Drag to rotate, use the mouse wheel to zoom, hover to inspect a node, and
  double-click to open its matching source or Skill in the library.
- Switch among relationship, parent/child, and semantic-type clustering.
- Node prominence reflects real library structure, local ratings, child counts,
  and GitHub popularity. Stable semantic and source-cluster colors make dense
  research libraries easier to distinguish.
- The compact liquid-glass Touch Bar stays visible without page scrolling.
- Atlas Deep Space and Atlas Fog Light are joined by the preserved Classic dark
  and light themes.
- Text and functional-icon sizes can be tuned independently in Settings.
- Parent and child Skills both support private local 1–5 star ratings and
  rating-first sorting.

## Polish and compatibility

- The sync/refresh icon is now a balanced continuous circle and rotates only
  while work is running. Reduced-motion preferences are respected.
- Operational pages use one alignment axis, consistent rounded surfaces, and
  strengthened dark/light contrast.
- Page navigation resets scroll position instead of inheriting the previous
  page's offset.
- Windows title-bar and taskbar icons include multiple raster sizes generated
  from the vector source, remaining crisp at common DPI scales.
- Portable first-run indexing repairs stale paths, scans real `SKILL.md`
  folders directly, hides internal router storage, and never counts generated
  router aliases as standalone local Skills.

## Installation

1. Download `AI-SkillHub-3.0.0.zip` from this Release.
2. Extract the whole archive to a normal writable folder.
3. Double-click `AI SkillHub.exe`.
4. Add a GitHub Skill source from Skill Library, then run Sync / Refresh.

Only folders containing `SKILL.md` are installed as Skills. Prompt-only
repositories remain reference sources.
