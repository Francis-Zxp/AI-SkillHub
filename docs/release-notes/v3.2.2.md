# AI SkillHub v3.2.2

## 中文说明

v3.2.2 是 v3.2.1 的正式补丁版，保留现有界面、操作流程和 MCP 安全边界。

- 首页数据球仅在窗口前台、页面可见且停留在首页时缓慢旋转。默认采用顺滑的 36 fps 环境动效；软件会根据实际绘制耗时自动降至 28 或 20 fps，拖动和缩放仍保持 60 fps。离开首页、失焦、隐藏或启用“减少动态效果”后不会持续绘制。
- MCP 新增“从 GitHub 快速导入”：粘贴 `owner/repo` 或公开仓库地址，软件只读取仓库根目录 `.mcp.json`/`mcp.json`，列出可安全带入的服务器。选择后仍会进入原有的脱敏差异确认，用户确认后才写入配置。
- 快速导入不启动 MCP、不执行仓库代码、不复制 Header 或凭据值；只带入受支持的命令、参数、URL 和环境变量名称。Header 引用需要用户以 `Header=ENV_NAME` 的形式自行填写。

## English

v3.2.2 is the formal patch release for v3.2.1. It preserves the existing interface, workflows, and MCP safety boundary.

- The dashboard data ball rotates only while the homepage is visible and focused. It uses a smooth 36 fps ambient budget, adapts to 28 or 20 fps when measured rendering cost rises, and keeps drag/zoom at 60 fps. It has no sustained drawing outside the homepage, while unfocused or hidden, or with reduced motion.
- GitHub quick import accepts `owner/repo` or a public repository URL, reads only a root `.mcp.json` or `mcp.json`, and lets the user choose a safe server draft before the existing redacted plan and confirmation flow.
- Quick import never starts an MCP server or repository code and never copies header or credential values. It transfers only supported commands, arguments, URLs, and environment-variable names.

## Release boundary

The fallback updater manifest is published only after signed assets are uploaded, anonymously downloaded, hash-compared, and verified with the embedded updater key.
