# AI SkillHub v3.1.12

v3.1.12 makes parent Skills reliably callable from every installed recipient and makes source-update exceptions visible instead of silently skipping them.

Highlights:

- Parent routers declare verified absolute child paths; Claude Code, Codex/ChatGPT, legacy Codex and Antigravity delivery now fails closed if an active parent entry or child file cannot be opened.
- Exact duplicate packaging copies are merged, while genuinely different same-name host variants remain available and clearly labelled.
- Settings lists sources blocked by local changes, missing Git metadata, timeouts or Git failures and gives a concise recovery direction.
- The add-source workflow can create a custom classification folder inline and place the full parent/child tree into it.

The signed updater manifest remains on v3.1.11 until v3.1.12 assets are built, independently downloaded and signature-verified.
