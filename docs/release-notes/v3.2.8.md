# AI SkillHub v3.2.8

日期：2026-10-02。本地候选：签名构建、本机安装与源码推送；不是公开自动更新发布。

## 更新链路

- 更新不再漏掉上游新增的子 Skill：稀疏检出的来源在拉取后按最新版本重新核对范围，补齐新增 Skill 目录与它们引用的小型依赖目录；本地自己改过或新增的文件保留，不做强制重置。导入与更新使用同一套规则。
- “更新全部来源”是可续跑的一次更新：每个来源单独显示已更新、无变化、固定版本、本地修改、失败或待继续，并记录检查时间与数量；时间预算用完时自动续跑，可随时停止。软件更新、检查来源版本、同步来源与刷新本地索引分开显示；显示跟踪分支，上游默认分支变化会明确提示。
- 修复：同步摘要文件带 BOM 时被误判为“全部完成”。

## 来源命名

- GitHub 来源统一为“项目名--作者”的目录与调用名，界面以项目名为主、作者弱化。设置页提供命名迁移：先预览旧调用名 → 新调用名，确认后执行，可续跑、可回滚，保留分类、备注、评分、启用状态与使用记录；不伪造旧调用名别名，不改用户自定义的中文标题。

## MCP

- Origin MCP “安装并连接”：独立 Python 运行环境（不改动 Anaconda 或系统 Python）、固定版本 origin-mcp 0.1.4、预览后写入宿主配置并先备份；验证依次检查运行环境、进程、MCP 握手与工具列表、Origin 桥接和一次只读调用。状态分为待安装、待启动 Origin、待连接、可用、异常，并显示最近验证时间；更新后需重新验证。不自动运行 README 中的命令或脚本，日志不含凭据。

## 视觉

- 全新天空岛：每个分类一座岛，面积按 Skills 数 + Prompt 来源数计算，空分类也能点开。使用随包打包、许可明确的模型（Quaternius CC0 套件、Poly by Google 的海鸥 CC-BY 3.0）与原创地形、岩体、云海、水面和动画；每类分类有不同的地貌与建筑；鸟群、人物、风与水有节奏地运动。支持暂停、省电模式、减少动态效果，WebGL 不可用或丢失时切换为分类列表。素材来源见天空岛页“素材与许可”与 docs/assets/sky-island-assets.md。
- 星图重新设计：安静的星场与天球大圆，克制的分类配色；普通、悬停、选中、相关与弱化状态清楚；名称互不遮挡且避开界面按钮，项目名在前、作者弱化；单击选中、双击打开。
- 新默认主题“天空 · 暮色 / 晴昼”，与两个场景同一套色彩；去掉首页口号与无意义的英文装饰，页面标题与说明更紧凑。原有主题仍可在主题菜单中选择；此前使用默认“棱镜 · 极夜”的用户会切换到新默认主题一次。

验证与边界见 docs/reviews/v3.2.8-implementation-and-validation.md。公共更新清单保持 3.2.4；朋友 Windows 10 机器的实际表现仍需单独验收。
