# AI SkillHub v3.2.5

本地候选版本，尚未发布到自动更新通道。

## 修复背景条栏阴影

3.2.3 修改的是星图 Canvas 光晕，而用户截图和 3.2.4 视频中的大面积阴影沿侧栏、顶栏、首页控制组、底部统计栏出现。这些是独立 DOM 元素的 CSS 阴影，旧修复没有覆盖。本版移除这些部位的大模糊阴影和叠加背景模糊，改用明确 RGBA 颜色与小范围阴影，同时处理后置 CSS 覆盖。

具体 Windows 10 WebView2/驱动触发条件尚未在朋友电脑取证，不能宣称已证明驱动问题。验收应使用本版安装包测试原故障电脑的深浅主题、窗口缩放及最小化恢复。

## 本机已有 Skills 可以被发现

进入 **AI 工具 → 本机 Skills**，自动扫描已有客户端技能目录。支持名称、说明、路径搜索，工具及管理状态筛选，查看原始 `SKILL.md` 和复制路径。填写项目绝对路径后，还可发现项目级技能。

“纳入技能库”进入原有本地导入、安全扫描与确认流程；如果已有导入草稿，会明确询问是否使用新路径。程序创建受管理副本，原目录保持不变，后续编辑不会回写原件。当前不包含外部技能直接删除、双向同步或插件缓存管理。

## 修复无 Git 来源更新

- 指纹由路径加文件大小改为逐文件 SHA-256，同长度内容修改也能识别。
- 新快照保存下载基准；检测到本地修改时保留本地内容并跳过更新。
- 旧快照没有基准时，只有本地与最新下载内容完全一致才自动建立基准。存在差异会保护性跳过，避免把本地编辑误当作可覆盖内容。
- 本地导入增加真实路径、内部目录链接与读取失败检查。

## 来源删除与跨盘移动可恢复

- 删除受管理来源时，先保护来源副本，再原子替换运行配置并重建索引和 Agent 投递。任一步失败都会恢复原配置和原来源，再重新对齐投递状态。
- 跨盘移动不再直接复制到最终目录。先复制到同目录的隔离暂存位置，逐文件 SHA-256 校验后才激活；原目录只会在完整副本可用后删除。
- 若原目录清理失败，程序保留两个完整路径并明确报告，绝不把半成品目录当作已完成备份。

## 验证与升级边界

浏览器测试覆盖六种 Atlas 主题、三种 DPI 和默认/禁用 GPU 两种启动方式；删除与跨盘移动还具有故障注入回归。它们不能替代朋友 Windows 10 的桌面 WebView2 验收。

请覆盖安装，保留 UserData；不要为了升级先卸载。公开自动更新清单仍指向已发布版本，只有完成候选包、签名及发布验收后才应切换。
