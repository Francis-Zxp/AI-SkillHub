### AI Skills를 한곳에서 정리하세요.

Skills를 모으고 원본 저장소를 업데이트하며 AI 도구에 연결하는 Windows 데스크톱 앱입니다. 검색 가능한 로컬 라이브러리에서 GitHub 저장소, 로컬 Skills, Prompt 자료와 MCP 설정을 관리합니다.

[**최신 정식 버전 다운로드**](https://github.com/Francis-Zxp/AI-SkillHub/releases/latest) · [업데이트 내역](CHANGELOG.md) · [문제 제보](https://github.com/Francis-Zxp/AI-SkillHub/issues)

## 주요 기능

| 작업 | AI SkillHub의 지원 기능 |
| --- | --- |
| 라이브러리 구성 | GitHub 저장소, 로컬 폴더, ZIP 또는 `.skill` 패키지를 가져옵니다. 지원되는 로컬 AI 도구 디렉터리에서 기존 Skills도 찾을 수 있습니다. |
| 필요한 기능 찾기 | 소스와 개별 Skill을 검색하고 분류, 태그, 평가, 메모를 관리합니다. 군도로 분류를 탐색하고 별자리 지도로 관계를 살펴봅니다. |
| 소스 업데이트 | 원본 Git 저장소를 확인하고 새 Skills를 동기화합니다. 소스별로 업데이트, 최신 상태, 실패 또는 건너뛰기 결과를 확인합니다. |
| 여러 AI 도구 연결 | Claude Code, Codex, Antigravity 등 지원되는 도구를 감지하고, 활성화한 Skills를 선택한 도구에 전달합니다. |
| 유사한 Skills 함께 보관 | 소스별 부모 진입점이 해당 소스의 하위 Skills를 유지합니다. 서로 다른 제작자의 유사한 기능을 함께 보관할 수 있습니다. |
| MCP 연결 관리 | 지원되는 클라이언트 설정을 확인하고 변경 사항을 미리 본 뒤 연결 설정을 적용하거나 스냅샷을 복원합니다. Origin MCP에는 전용 설치 및 연결 검사도 있습니다. |

## 세 단계로 시작하기

1. **앱 설치**: 최신 정식 버전에서 `AI-SkillHub-<version>-setup.exe`를 다운로드합니다. ZIP 패키지도 제공됩니다.
2. **소스 추가**: Skill Library에서 소스를 가져오거나, AI Tools에서 기존 로컬 Skills를 찾습니다.
3. **AI 도구 선택**: 활성화한 Skills를 동기화합니다. 소스를 열면 사용 방법을 확인할 수 있습니다.

인터페이스는 영어, 중국어와 한국어를 지원합니다. 테마, 글자 및 아이콘 크기, 애니메이션과 절전 모드를 조절할 수 있습니다.

**Claude Desktop**: Windows 로컬 Code를 먼저 초기화하고 AI SkillHub에서 Claude를 연결·동기화하세요. 새 로컬 Code 세션에서 `/`로 부모 Skill을 찾습니다. Chat/Cowork 계정 Skills 및 Cloud/SSH/WSL은 별도 경로를 사용합니다. [3.2.17 안내](docs/release-notes/v3.2.17.md)를 참고하세요.

## Skills, Prompts와 MCP

- **Skills**는 `SKILL.md`를 포함하며 에이전트가 불러올 수 있는 기능을 설명합니다. 부모 진입점은 같은 소스의 하위 Skills를 정리합니다.
- **Prompts**는 재사용 가능한 지시문이나 참고 자료입니다. Markdown 파일이 있다는 이유만으로 Prompt 저장소를 Skill로 설치하지 않습니다.
- **MCP**는 AI 클라이언트를 외부 서버나 앱에 연결합니다. 설정을 가져오는 것만으로 모든 서버 의존성이 설치되거나 서비스가 실행되지는 않습니다. 지원되는 연동은 앱의 연결 검사로 확인하세요.

## 업데이트와 데이터

**소스 업데이트**는 원본 저장소의 변경 사항을 가져옵니다. 고정 버전, 로컬 수정 사항 또는 원본 주소가 없는 소스는 별도 처리가 필요할 수 있습니다. 업데이트 결과에서 각 소스의 상태와 이유를 확인할 수 있습니다. 메모와 평가는 원본 콘텐츠와 별도로 저장됩니다.

**앱 업데이트**는 서명된 공식 릴리스 설치 패키지를 사용합니다. 설정에서 확인하고 설치하거나, 최신 릴리스 페이지에서 직접 다운로드할 수 있습니다. 이전 버전 정보는 [업데이트 내역](CHANGELOG.md)에 모아 두었습니다.

라이브러리, 설정, 평가와 로컬 인덱스는 프로그램 디렉터리 밖에 저장됩니다.

```text
%LOCALAPPDATA%\AI SkillHub\UserData\
```

검사 중 가져온 소스의 스크립트를 실행하지 않습니다. 소스 검토, 진단과 복원 가능한 스냅샷을 통해 변경 사항을 적용하기 전에 내용을 확인할 수 있습니다. 공개 릴리스 패키지에는 개발자의 개인 라이브러리가 포함되지 않습니다.
