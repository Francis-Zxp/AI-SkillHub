# Signed updater metadata mirror

`latest.json` is copied here only after the matching signed GitHub Release assets
are publicly downloadable and verified. The file is served by Raw GitHub and
jsDelivr as fallback metadata for the desktop updater.

Do not publish a future-version manifest before its installer and `.sig` asset
exist. The manifest never contains private keys; it contains the public installer
URL and the detached signature generated by the formal release build.
