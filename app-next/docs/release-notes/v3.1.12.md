# AI SkillHub v3.1.12

This release makes parent Skills callable and updateable across Claude Code, Codex/ChatGPT, legacy Codex, and Antigravity.

## Highlights

- Every parent router now declares recipient-openable absolute child paths and is verified from every installed Agent entry before delivery reports success.
- Same-name child Skills are preserved when their content differs, while byte-identical host packaging copies are collapsed.
- GitHub imports clearly show whether they are updateable Git clones or non-updateable snapshots, and snapshots can retry Git before promotion.
- Deep Windows repositories use repository-scoped long-path support. The exact Git for Windows Schannel credential failure retries with repository-scoped OpenSSL without changing global Git settings.
- Complete Prompt repositories are bounded before checkout through committed GitHub tree metadata, then scanned without executing repository scripts or hooks.
- Source deletion first moves the managed folder to a recoverable backup and then cleans routes, shared Skills, and Agent links.
- Source import can create a custom classification folder and keep the whole parent/child tree together.

## Verification

- Live routing gate: 43 active parents, 921 declared child references, and 921/921 openable entries for each installed Claude, Codex, legacy Codex, and Antigravity recipient.
- Real GitHub import gates cover deep Windows paths and the Prompt repository update path.
- Frontend build, Node behavior contracts, Rust tests, formatting, linting, and signed release checks are required before publication.
