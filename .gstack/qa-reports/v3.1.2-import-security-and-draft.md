# v3.1.2 import security and draft QA

Date: 2026-08-08

## Reproduction

- Real recipient repository: `Imbad0202/academic-research-skills-codex`.
- v3.1.1 result: 658 findings across roughly 3509 files; source remained in
  staging and could not reach the evidence-confirmation flow.
- Navigation result: leaving Skill Library unmounted the Add Source form and
  discarded its fields.

## Root cause and fix

- Every script extension created an individual medium finding, duplicating an
  executable inventory already present in the report.
- Multi-keyword rules matched tokens anywhere in a whole file, and high-risk
  examples were not distinguished from operational Skill instructions.
- Form state lived only inside the mounted React component.
- v3.1.2 keeps the script count, uses same-line rules, downgrades only known
  non-executed documentation/test contexts to explicit review, and preserves
  true operational blockers.
- A validated local-only form draft now persists durable fields; transient
  execution and security state are excluded.
