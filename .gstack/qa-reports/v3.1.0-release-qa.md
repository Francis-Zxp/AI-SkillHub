## Issues found and closed

1. Rust library tests failed to start on Windows because the test executable did not link the generated Common Controls v6 manifest resource. The build now adds the generated resource library to the native search path and explicitly links it for Windows tests.
2. Cancellation initially killed only the parent Git process. The Windows implementation now terminates the complete process tree, preventing inherited pipes from keeping the operation alive.
3. The real Imbad repository exceeded legacy Windows Git path behavior in recipient QA. The QA clone now uses process-local `core.longpaths=true` without changing the user's global Git configuration.
4. A 150% DPI visual check exposed top-bar vertical overflow at compact widths. Responsive layout constraints were corrected and re-tested in real Chrome and the formal Tauri executable.

## Release disposition

PASS. No release blocker remains for v3.1.0. MCP management and Codex Plugin Doctor remain intentionally read-only in this version.
